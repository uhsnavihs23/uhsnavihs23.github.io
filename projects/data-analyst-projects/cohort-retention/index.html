Customer Cohort & Retention Analysis

End-to-end Python analysis on 25,951 e-commerce transactions to identify user retention patterns and lifetime value across monthly acquisition cohorts.

Key Business Insights

  • High Initial Drop-off: There is a significant churn rate (approx ~60%) after the first month of acquisition across all cohorts. A targeted 30-day onboarding sequence is highly recommended.
  • Long-term Stabilization: Customers who survive past Month 3 exhibit strong loyalty, maintaining a flat retention curve thereafter.
  • Cohort Quality: Early-year cohorts (Jan/Feb) demonstrate higher lifetime value and baseline retention than late-year acquisitions.

3 Methodology & Python Implementation

The analysis was performed using Pandas for data wrangling and Plotly for interactive visualization. The raw data consisted of transactional records featuring customer_id, transaction_date, and amount.

cohort_analysis.py 
import pandas as pd

# 1. Extract Invoice Month and Acquisition Cohort Month
df['transaction_month'] = df['transaction_date'].dt.to_period('M')
df['cohort_month'] = df.groupby('customer_id')['transaction_date'].transform('min').dt.to_period('M')

# 2. Group by cohort and count unique customers per transaction month
cohort_data = df.groupby(['cohort_month', 'transaction_month']).agg(n_customers=('customer_id', 'nunique')).reset_index()

# 3. Calculate Cohort Index (Months since acquisition)
cohort_data['period_number'] = (cohort_data.transaction_month - cohort_data.cohort_month).apply(lambda x: x.n)

# 4. Pivot into a Matrix
cohort_counts = cohort_data.pivot(index='cohort_month', columns='period_number', values='n_customers')

# 5. Convert to Percentages (Retention Matrix)
cohort_sizes = cohort_counts.iloc[:, 0]
retention_matrix = cohort_counts.divide(cohort_sizes, axis=0) * 100
