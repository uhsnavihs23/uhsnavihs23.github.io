# uhsnavihs23.github.io

Personal portfolio site built with Jekyll and the Chirpy theme, hosted on GitHub Pages.

## What's here

A collection of work across three areas:

- **Data Analytics** — exploratory analyses on food delivery, retail shopping trends, and campus energy consumption
- **Web Apps** — browser-based tools including a movie recommender, book explorer, image editor, news aggregator, and GitHub profile finder
- **Policy Writing** — articles and tools on Indian governance and public policy, including an AI-assisted policy brief generator powered by live news headlines

## Stack

- Jekyll + Chirpy theme
- GitHub Pages for hosting
- Vercel for serverless API proxy
- Vanilla HTML/CSS/JS for all project tools

## Structure
_posts/ → project and article entries
_tabs/ → sidebar navigation pages (About, Timeline)
projects/ → standalone tool pages
assets/ → CSS, images, reports
categories/ → category index pages
