# Shivanshu Sharma - Portfolio Website

Welcome to the repository for my personal portfolio website!

## 🎨 Design System

This project strictly adheres to the UI/UX principles outlined in our **Single Source of Truth** for design: [AWESOME_DESIGN.md](./AWESOME_DESIGN.md).

Before contributing or generating new pages, please review the design document to ensure you maintain perfect visual consistency across the entire site.

## 🚀 Features
- High-contrast, accessibility-focused Light & Dark modes.
- Strict adherence to structural geometric design (Vercel/Geist principles).
- Immersive "Retro Mode" (IE6 Chrome simulation) for nostalgic viewing.
- Seamless, responsive layouts powered by Tailwind CSS.
